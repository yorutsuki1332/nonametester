# LIGHTNING LIFESTYLE — 更新日誌

## v0.3.1

**版本日期：** 2026年11月12日  
**更新版本：** v0.3.1（型別清理、本機圖片、大型選單）

### 程式品質

- 清掉 ESLint 的 64 個錯誤與 25 個警告，包含明確的 `any`、effect 裡的同步 `setState`、未使用變數，以及上架頁對已刪除函式的引用。
- 新增 `src/lib/errors.ts`，集中處理錯誤訊息與 Firestore 文件欄位。
- 刪除過期的 `.next` 型別快取。它還在尋找舊的 `app/page.js`，清掉後 `tsc --noEmit` 可以通過。

### 商品圖片

- 本機代理會把 Vercel Blob 網域解析成 `198.18.x.x`。在 `next.config.ts` 加上 `images.dangerouslyAllowLocalIP`，允許的來源仍只有既有的 Blob 網域。
- 沒有圖片的商品，首頁卡片與商品頁改顯示分類圖示和商品名稱。

### 大型選單

- 首頁分類列改成大型選單：上方膠囊、左側分類、中間三欄子分類、右側兩張精選卡。
- 滑過左側分類會等 120 毫秒才切換，避免斜向移動時誤觸隔壁分類。
- 選單打開時，右側預設是「全部選品」。
- 每次滑過或點左側分類，右側內容都會再淡入一次。

### 首頁行為

- 「全部選品分類」不再永遠維持選取色。點它會打開面板，不會在同一次點擊裡立刻關掉。
- Firestore 商品更新時，會保留目前的分類與搜尋條件。
- 商品還沒載入完成時顯示「正在載入選品...」。

### v0.1 — 2026年10月30日

**更新版本：** v0.1（Architecture & UI Modernization）

網站由傳統 HTML 遷移至 Next.js App Router、Tailwind CSS 與 Vercel。

#### 新增

- 前端遷移至 Next.js App Router。
- `globals.css` 加入 `max-width: 768px` 的手機與平板斷點。
- 商品詳情頁與首頁卡片支援 `touchAction: 'pan-y'` 與左右滑動切換圖片。

#### 修改

- 處理 Next.js 16 的靜態預渲染限制，修復 `new Date()` 造成的編譯錯誤與動態連線相容問題。
- 重構商品詳情頁的圖片切換，第一張圖片使用 `priority` 載入。
- 調整手機版導覽列的排列與間距，縮短搜尋框與頂部 Logo、返回按鈕的距離。
- 商品詳情頁與商品列表改為雙欄與單欄自適應網格。

#### 刪減

- 清掉不相容於 React 的原生 HTML 腳本與舊路由程式。
- 移除硬編碼寬度（例如 450px），改由 Tailwind 控制版面。

### v0.0 — 2026年10月24日

**更新版本：** v0.0（Performance & Seller Center Image Engine Upgrade）

#### 後台圖片處理與上傳引擎

**適用頁面：** `admin.html`（新增商品）、`products_list.html`（上架貨品）、`discontinued_list.html`（已下架貨品）

- 引入 `browser-image-compression`。新增或修改商品時，圖片會在前端自動壓縮（單張最大 0.5MB、邊長最大 1200px）。
- 圖片上傳改為 `Promise.all` 平行處理。
- 商品編輯視窗（包含已下架商品）統一支援多圖拖拉上傳、動態預覽刪除，上限 15 張。

#### 前台圖片載入

**適用頁面：** `index.html`（首頁）、`product.html`（商品詳情）

- 每個商品輪播只在渲染時載入第一張圖片，其餘網址放在 `data-src`，切換、點指示點或滑動時才載入。
- 圖片標籤加入 `loading="lazy"` 與 `decoding="async"`。
- 移除自動輪播。電腦端可用箭頭與指示圓點切換；手機端支援左右滑動，並避免滑動時誤觸商品連結。

#### 營運與資料庫

- 訂單編號與商品 SKU 自動生成時，修正年份與流水號的比對，維持編號唯一與排序正確。
- 完善 `discontinued_products` 與 `products` 之間的重新上架與永久刪除流程。
